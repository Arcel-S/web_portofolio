### Executive Summary
Scheduly adalah aplikasi penjadwalan shift karyawan otomatis yang memanfaatkan algoritma *Simulated Annealing* berkecepatan tinggi. Sistem ini berjalan secara *serverless* di atas Cloudflare Workers, menghasilkan jadwal optimal yang mempertimbangkan seluruh constraint bisnis secara real-time.

### Key Highlights & Features
- **Simulated Annealing Engine:** Algoritma optimasi metaheuristik yang menghasilkan jadwal shift optimal dengan menyeimbangkan beban kerja, ketersediaan karyawan, dan aturan bisnis secara otomatis.
- **Serverless di Cloudflare Workers:** Infrastruktur edge computing tanpa server untuk latensi ultra-rendah dan skalabilitas global tanpa konfigurasi.
- **Antarmuka React Modern:** UI industri-grade yang intuitif dengan tampilan kalender interaktif dan fitur drag-and-drop untuk swap jadwal antar karyawan.
- **Ekspor Multi-Format:** Jadwal final dapat diekspor langsung ke file Excel (.xlsx) untuk kebutuhan administrasi atau file Kalender (.ics) yang kompatibel dengan Google Calendar dan Outlook.
